Navisual 使用手册

最后更新：2026 年 11 月 22 日 · 适用于 Windows 10 和 11

Navisual 是一款 Windows 软件，在任何软件里一步一步带你完成任务。你说出想做的事， Navisual 看一眼你选定的程序，想好下一步，再用屏幕上的指针、字幕和语音告诉你该点哪里。它从不替你点击或输入：每一步都由你自己完成。

这份手册讲的是界面上不那么一目了然的部分。第一次用？从入门开始。遇到问题？去看问题排查。

快速解答

Navisual 会替我点击或输入吗？

不会。Navisual 只告诉你该做什么：控件上的指针、一行字幕和一句语音说明。每一次点击和按键都由你自己完成，所以你随时可以停下、换个做法，或者不理它。

Navisual 免费吗？

免费下载，每台电脑含 30 次免费请求，不用注册，也不用 API Key。一次请求就是问一次 AI，一次可能包含不止一步。用完之后，可以购买金币、用你自己的 API Key，或者免费使用本地 AI 模型。

需要注册账户吗？

不需要。免费请求、你自己的 API Key 和本地模型都不需要账户。购买金币需要账户，账户也能让你的金币和购买记录在不同电脑之间保留。

免费请求用完以后要花多少钱？

金币 5 美元起，可买 1,000 金币。每次请求按质量档位消耗 6、12 或 18 金币，所以 5 美元大约能用 55 到 165 次。金币不会过期。用你自己的 API Key 时由服务商直接向你收费，本地模型则完全免费。

Navisual 支持哪些软件？

几乎所有 Windows 软件都能用。已经在 Microsoft Word、Excel、PowerPoint、Outlook 和 OneNote，Chrome 和 Edge，文件资源管理器和 Windows 设置，以及 Blender、Krita、VS Code、VLC 和 LibreOffice 里测试过。在 Photoshop、SolidWorks 这类自己绘制界面的软件里，AI 根据它在截图里看到的内容来指向。

Navisual 支持哪些 Windows 版本？

Windows 10（1809 或更高版本）和 Windows 11。暂不支持 macOS 和 Linux。

Navisual 会一直盯着我的屏幕吗？

不会。只有在你求助或要下一步的时候，Navisual 才会截一张图给 AI。唯一的例外是你自己打开的自动推进：它在你的电脑上大约每秒比较两次屏幕，只有当屏幕变化大到看起来你已经做完这一步时，才去问 AI。

Navisual 会把什么发给 AI？

你选定窗口的截图（其他部分都会被涂灰），加上你输入的内容、窗口标题、这个窗口里各个控件的名称和状态、你在这个窗口里最后点过的控件，以及你的 Windows 版本。完整清单见隐私政策。

Navisual 能离线运行吗？

能，通过 Ollama 或 LM Studio 这类本地服务器使用本地 AI 模型。什么都不会离开你的网络，也什么都不记录。你需要一个能看图的模型，指引的质量取决于这个模型。

Navisual 支持哪些语言？

界面有英文、简体中文和繁体中文。AI 用你输入的语言回答；如果 Windows 装了这种语言的语音，还会把回答读出来。

在中国大陆能用吗？

能用，不需要 VPN。在中国大陆，托管服务（免费档和付费档）的请求由通义千问和 DeepSeek 处理。Google 登录在大陆可能打不开，用邮箱注册和登录就行。

1. 入门

你需要：Windows 10（1809 或更高版本）或 Windows 11，以及网络连接（使用本地模型时不需要）。 Navisual 还需要 WebView2：Windows 11 自带，Windows 10 上会自动安装。

安装。从首页下载并运行安装包。安装包有代码签名，但新发布的软件仍然会触发微软的 SmartScreen 提示。如果看到它，点更多信息 → 仍要运行。

第一次启动。你会看到一段简短的隐私说明，讲清楚 Navisual 截取什么、发到哪里、记录什么。不需要账户：免费档会匿名登录，给你 30 次请求来试用。

之后的用法总是一样的：

  1. 打开你需要帮助的软件，让它保持可见。
  2. 在 Navisual 的输入框里写下你想做的事，用平常说话的方式就行，比如“用这些数据做一个数据透视表”或“给这个立方体倒角”，然后点开始指引。输入框里可能已经有一条建议的任务：可以直接用，也可以改写。
  3. 跟着指针做。Navisual 截一张图，想好下一步，在要点的按钮上画出标记，同时用语音和字幕说明。
  4. 自己做完这一步，然后按 Ctrl+` 进入下一步。

Navisual 只在需要的时候才给 AI 截图：你提问的时候，或者你要下一步的时候。唯一的例外是你自己打开的自动推进。

任务完成后，点＋ 新任务重新开始。想修改或纠正你的要求，直接在输入框里写，然后点 ↩ 追问。

面板放在哪里

面板放在哪里 Navisual 都能工作。下面只是建议，不是要求：最好的位置是不挡住你正在用的软件。

  • 一块屏幕：停靠或收起最合适。在 ··· 菜单里选停靠左侧或停靠右侧， Navisual 占屏幕一侧的一条，其余留给你的软件，宽屏尤其合适。也可以把 Navisual 收起成金鱼图标，每一步按 Ctrl+`：指针、字幕和语音照常工作。屏幕比较小时，收起可能更合适。
  • 两块或更多屏幕：建议把面板单独放在一块屏幕上，你正在用的软件放在另一块。软件占满整块屏幕，步骤也一直在旁边看得到。

3. 选择 Navisual 看哪里

默认情况下，Navisual 看的是最前面的那个窗口。标题栏里的程序标签显示当前是哪个程序。你固定一个窗口时，它的边上会短暂出现一圈轮廓，让你看清共享的是什么。

点程序标签可以更改。有三种选择：

  • 某一个窗口。选中它就会固定（📌）：即使你点了别的地方，Navisual 也一直看这个窗口。只要你要在几个窗口之间来回切换，或者这个软件会弹出抢焦点的对话框，就该这样选。最小化的窗口也会列出来，选它会把它还原。
  • 整个桌面（多显示器时是屏幕 1 / 屏幕 2），用于跨程序的任务，比如把文件从资源管理器拖进另一个程序。多显示器时请选单独的一块屏幕，不要选整个桌面：把所有屏幕拼成一张图，细节会缩小到 AI 看不清的程度。
  • 自动识别，回到跟随最前面窗口的方式。

只共享一个窗口时，它以外的所有内容（包括叠在它上面的其他程序，以及 Navisual 自己的面板）在发送前都会被涂灰，所以图里只有你的目标程序。随图一起发送的其他内容见第 14 节。

如果固定的窗口关闭或被隐藏，会出现一条提示和重新选窗口按钮。你选好之前， Navisual 不会改看别的东西。如果窗口回来了，提示会自动消失。固定的窗口如果只是最小化，需要你从任务栏把它还原。

如果没有可以指引的窗口，Navisual 会提供在这块屏幕上引导或选择程序。除非你这样选，否则它不会擅自扩大看的范围。

4. 跟着指引做

每一步都会给你一条说明，读出来的同时在屏幕上显示字幕；如果 Navisual 能确定是哪个控件，还会在按钮上画出标记。

如果没有出现标记，你会看到一行提示，说无法给出指针。这是故意的：Navisual 宁可什么都不指，也不愿指错。有些界面确实无法从外部读取，比如 3D 视图、画布、游戏。文字说明仍然是对的，只是少了箭头。

→ 下一步进入下一步。自动推进（在操作按钮那一行）会在屏幕变化大到看起来你已经做完这一步时，自动做同样的事。每次启动软件时它都是关着的，这是故意的：它每触发一次就可能用掉一次请求。自动推进适合又长又明确的操作；需要边做边想的，适合手动一步一步来。如果它触发得太频繁或太少，调整设置 → 屏幕指引 → 自动推进里的滑块。

自动推进会在两种情况下自己暂停：屏幕一直在变却没有明确的下一步时；以及免费次数只剩 5 次时暂停一次，免得它自己把最后几次用掉。面板上会说明原因，要不要重新打开由你决定。免费次数用完时它会停止。

需要你输入的内容，都会放进剪贴板。终端命令、网址、文件名、表单里要填的文字都是这样。某一步需要输入时，准确的文字会替你复制好，这一步旁边会显示 📋 标记，你粘贴就行，不用重新打字。快捷键是有意的例外：快捷键会写在说明里，因为它要按，不能粘贴。Navisual 从不替你运行命令或按任何键：你看过之后，自己粘贴、自己按回车。

跨多个程序的任务不需要任何设置：在浏览器里下载、编辑文件、在终端里运行命令，你在哪个窗口里， Navisual 就跟到哪个窗口。如果你希望它在你来回切换时一直盯着一个程序，就固定那个窗口（第 3 节）。

有时 Navisual 会问你一个问题，而不是给出一步。在回复框里写下答案，按回车。如果它看到的信息不够，无法确定，你得到的会是诚实的回答：“把正确的窗口切到前面来”。

5. 快捷键

用快捷键操作 Navisual 最顺手，因为快捷键不会把键盘焦点从你的程序上移走。点 Navisual 面板会移走焦点：这时 Windows 会吞掉你在目标程序上的下一次点击，因为那一下用来重新激活窗口了，你之前打开的菜单也会关掉。如果你遇到过一个按钮要点两次，原因就在这里。用快捷键就不会这样。

操作默认作用
下一步Ctrl+`进入下一步：最常用的一个
切换图标模式Ctrl+Shift+`把面板缩成金鱼图标，再按一次还原
语音输入Ctrl+D按住说话：说出你的请求，不用打字
标记为错误未设置告诉 Navisual 这一步不对（第 6 节）；需要你自己指定按键
暂停 / 取消未设置停止指引；需要你自己指定按键

` 是反引号键，在 1 的左边、Esc 的下面。最后两个默认不设置，是故意的，免得和你已经在用的快捷键冲突。在设置 → 快捷键里可以设置你自己的按键，也可以用 ✕ 清除任何一个。

下一步和标记为错误只在正在指引某一步时才占用，所以没有任务在进行时，这些按键仍然属于你的其他程序。如果某一步让你按的快捷键正好也是 Navisual 的快捷键，Navisual 会在这一步里把它让出来，并在面板上说明。

6. 指错了怎么办

每条说明下面都有一个✗ 这步不对按钮。点它会问你哪里不对，不同的回答会触发完全不同的处理：选得准，修正就来得更好、更快：

你选会发生什么
位置不对
（说明是对的，标记落在了错的按钮上；有标记时才显示）		Navisual 在你的电脑上本地重新搜索屏幕，排除你否定的那个位置。不用问 AI，通常一下就好：建议是对的，只是没瞄准。如果第二次还没找对，就交给 AI。
找不到
（什么都没标出来，或者说明里的东西不在屏幕上）		同样先在本地重新搜索，然后重新看一遍你的屏幕。
指引不对
（这一步不是你需要的）		直接回到 AI，告诉它哪里错了，让它重新规划。
已经做过了继续往下。如果下一步已经准备好，会立刻进入，不用花一次请求。

都不合适？在输入框里写下哪里不对，然后点↩ 追问。你写的话一定会发给 AI。如果 Navisual 看错了程序，先点一下正确的窗口，再点 ✗。你的选择会被记录下来，用来改进指引，但从不记录你的屏幕；你输入的文字也会一起记录，除非你把它关掉（第 14 节）。

出现几个带编号的框，而不是一个箭头？说明 Navisual 找到了不止一个合适的目标（比如三个格子都写着“合计”），它不打算瞎猜。① 是它认为最可能的。点你要的那个：你的点击就是回答，没有对话框要关。如果都不是，点 ✗。

7. 最近的任务和导出

Navisual 会边做边把每个任务保存在你的电脑上。🕓 最近的任务列出最近的 20 个：点一个就能重新打开，从上次停下的地方接着做。更早的会话连同截图一起移到回收站。

保存的会话包含对话、你的任务、计划、你点过什么，以及每一步的截图。如果不想保留截图，关掉设置 → 屏幕指引 → 会话保存；这样重新打开的会话会在下一步重新读取屏幕。无论哪种方式，重新打开的会话都会跟随你接下来点进去的那个程序。

最近的任务里的导出会把你的会话（或者只是你选中的几个）各存成一个独立的 HTML 文件，任何浏览器都能打开。打开文件…可以在面板里查看这样的文件；只有你在里面继续操作，它才会加入最近的任务。截图是你屏幕的图片，发给别人之前请先看一遍。

8. 语言、朗读和语音输入

界面语言。Navisual 的界面有英文、简体中文和繁体中文，默认跟随你的 Windows 语言；可以在设置 → 屏幕指引 → 界面语言里更改。

AI 的语言。不管界面设成什么语言，AI 都用你输入的语言回答。

语音朗读使用 Windows 里安装的语音。设为自动时，每条回答都用它自己的语言、由已安装的该语言语音读出来。在设置 → 音频里可以选择你喜欢的语音，或者关掉朗读。想临时静音或隐藏字幕，用 ··· 菜单。

语音输入让你说出请求：按 Ctrl+D 或点 🎤 按钮。你说的话会出现在 Navisual 的输入框里，发送前可以修改。它需要麦克风和网络连接，因为你的音频会发送给微软的在线语音服务。可以在「设置 → 音频」里关掉。语音识别必须在你开口之前就知道你说的是什么语言。设为自动时，它按 Navisual 的界面语言来听；如果界面跟随 Windows，就按你的 Windows 语言来听。所以如果你说的是另一种语言，请在那里设置语音语言。可选的有英语、法语、德语、西班牙语、日语、普通话、台湾普通话、粤语、韩语和葡萄牙语。

9. AI 服务商和费用

Navisual 支持多种 AI 后端，在设置 → 服务商里选择。

  • 托管：免费。不用 Key，不用账户，每台设备 30 次请求。注意：免费的 AI 模型通常会保留请求（包括你的截图）用来训练。如果你在意这一点，请改用下面任何一种方式。（详见隐私政策。）
  • 托管：按用量付费。5 美元起充值，Navisual 替你调用更强的付费模型，你不用管理任何 API Key。付费服务商声明不会用你的数据训练模型。
  • 自带 Key。Anthropic、Google Gemini、OpenAI、DeepSeek、Qwen，或任何兼容 OpenAI 接口的服务。请求直接从你的电脑发给那家服务商，不经过我们的服务器，由服务商直接向你收费。两点说明： DeepSeek 只有选 deepseek-flash 时才能看屏幕，就是设置里标着“能看屏幕”的那个，之前选了 deepseek-v4-flash 的会自动换成它。选 deepseek-v4-pro 时，Navisual 不发送截图， AI 只能根据你的文字、窗口标题和控件名称来判断，看不到画面。另外，在中国大陆，Qwen 是推荐的云端选择。
  • Ollama 或其他本地服务器。在你自己的电脑或网络上运行。什么都不会离开，不收费，不记录，断网也能用。你需要一个能看图的模型，比如 llama3.2-vision，或者通过「自定义」服务商接入任何兼容 OpenAI 接口的本地服务器（LM Studio、llama.cpp、vLLM）。质量完全取决于你运行的模型。

金币和质量档位

托管服务用金币付费。1 金币固定为 0.005 美元。你选的质量档位决定由哪个模型回答，以及每次请求花多少金币：

档位每次请求的金币适合
速度档（Speed）6最快、最便宜；适合简单、文字多的界面
主力档（Regular）12综合最好的默认选择
智能档（Smart）18在含义模糊或画面密集的界面上最强

所以 5 美元可买 1,000 金币，大约 55 到 165 次请求。在设置 → 账户里购买金币（5 到 500 美元；付款页面会在浏览器里打开，需要账户）。金币不会过期，除法律要求的情况外不予退款，详见服务条款。有注册优惠时，软件里会显示。

不管选了哪个档位，都会先用免费次数。只剩 5 次时，面板会提醒你。

选哪个？

如果只是试试 Navisual，免费档就够了。如果用在实际工作上，选按用量付费或自带 Key：两者都明显更准确，也都不会让你的屏幕进入训练数据。如果你的屏幕内容完全不能离开你的电脑，只有本地模型能从设计上保证这一点。

余额显示在标题栏，点它就能去充值。ⓘ 关于里的用量标签页显示你的余额，并估算你自己的 Key 花了多少钱。

10. 针对特定软件的支持

Navisual 通过大多数 Windows 软件本来就公开的无障碍信息来读取界面，所以按钮、菜单和功能区几乎在哪里都工作得很好。有些软件需要更多帮助。

浏览器是最好的情况之一：网页公开了丰富的结构，所以在网页应用、表单或管理后台里的指向通常是精确的。 Chrome 和 Edge 还有专门的快速通道。

终端（Windows 终端、PowerShell、编辑器里的命令行）靠剪贴板而不是指针：那里没有按钮可指，所以 Navisual 给你一条可以粘贴的命令（第 4 节），从不替你运行。

Excel、Word 和 PowerPoint 有专门处理：Navisual 能把一个单元格地址、文档里的一句话或幻灯片上的一个形状，精确定位到像素，而不是凭眼睛猜。不需要任何设置。

Blender 有一个可选插件。Blender 的整个界面都是自己画的，从外部看只是一张图：这个插件让 Blender 告诉 Navisual 它的工具在哪里、你现在处于哪个模式、用的是哪个笔刷。工具栏和属性标签页的指引会可靠得多。

  • Navisual 发现你在用 Blender 时会提出安装。点安装，它会把文件复制到 Blender 的插件文件夹。
  • 然后重启 Blender，打开 Edit → Preferences → Add-ons，搜索 Navisual，勾选它。这一勾就是你同意的那一步；Navisual 不能也不会替你勾。
  • 它是只读的：只回答关于界面的问题，不能点击、输入、运行命令，也不会碰你的文件。它只在你自己的电脑上监听，不向互联网发送任何东西。
  • 每个 Blender 版本都有自己的插件文件夹，所以你用的每个版本都要装一次。随时取消勾选就能关掉它。

自己绘制界面的软件（SolidWorks 的命令功能区、Photoshop 和 GIMP 的工具箱、3D 视图、大多数游戏）没有公开任何可供 Navisual 在本地读取的信息。这不代表 Navisual 不能在里面指导你。没有东西可读时， AI 会像你一样去看截图，根据看到的内容来指向。在能力强的模型上效果很好，连它从没见过的界面也行。

变化的是怎么指：标记往往是控件周围的一片区域，而不是紧贴控件的轮廓。而且这里比软件的其他地方都更依赖模型：靠看来读一个陌生界面，本来就比读一个标签难得多。如果这类软件里没有出现指针，请在设置 → 服务商里提高质量档位（或者用你自己的 Key 和一个当前能看图的模型）。在这里，这一项改动比任何其他设置都重要。

注意，这些软件里你最常需要帮助的部分（菜单、偏好设置、对话框、属性面板）通常不是自己绘制的，表现正常。同一个软件在菜单里指得很准、在画布上只是大概，这很常见。

很小的文字是另一种难点：屏幕文字识别有一个尺寸下限，排得很密的界面标签可能会漏掉。不管怎样，你都会得到文字说明。

经验笔记。如果在某个软件里找一个命令试了不止一次，Navisual 会记下它在哪里，下次第一次就能找对。笔记只包含界面上的标签文字，保存在你的电脑上，之后在这个软件里的请求会带上它们。在设置 → 屏幕指引 → 经验笔记里可以查看、修改或删除。

11. 设置

点标题栏里的 ⚙ 按钮打开设置。一共有五个标签页：

标签页里面有什么
服务商AI 服务商、API Key、模型、质量档位
账户登录或注册账户、购买金币、修改密码、退出登录、注销账户
屏幕指引界面语言、指针颜色和粗细、实时字幕、任务建议、自动推进及其灵敏度、会话保存、经验笔记，以及你输入的内容
快捷键全部五个快捷键
音频语音朗读和语音选择、语音输入、语音语言

应用保存设置并保持窗口打开；确定保存并关闭。不需要重启。重置所有设置会恢复所有标签页，而不只是当前这一页：你的 API Key 会保留，但服务器地址和模型选择不会。

12. 更新、你的数据、卸载

更新。Navisual 启动后不久会检查有没有新版本，有的话会在标题栏显示提示。你也可以在 ⓘ 关于 → 检查更新里手动检查，它会告诉你已是最新版本、有新版本，还是检查失败；有新版本时点安装并重启。

你的数据。设置、保存的会话、经验笔记和日志都在 %LOCALAPPDATA%\com.navisual.app。API Key 和你的登录信息另外保存在 Windows 凭据管理器里，按你的 Windows 用户加密。

卸载。在 Windows 设置的已安装的应用里删除 Navisual（Windows 10 上是应用和功能）。如果之后你保存的会话和设置还在，删除上面那个文件夹即可。

注销账户。在设置 → 账户 → 注销账户里操作。注销是永久的，金币不予退还。已存储的记录如何处理，见隐私政策。

13. 问题排查

现象怎么办

某个程序里从来不出指针这个程序很可能是自己绘制界面的（3D 视图、画布、游戏），所以指向要靠 AI 自己看屏幕。在设置 → 服务商里提高质量档位：在这里它比在任何地方都管用。见第 10 节。
指引的程序不对点标题栏里的程序标签，固定你真正要的那个窗口。
“你固定的窗口已经关闭或被隐藏”点重新选窗口再选一次，或者选自动识别。
“你固定的窗口已最小化”从任务栏把它还原，然后重试。
请求超时通常是免费模型负载太高、太慢。再试一次，或者在设置里换一个服务商。
“免费次数已用完”在设置 → 账户里购买金币，或者在设置 → 服务商里填入你自己的 API Key 或本地模型。

Google 登录没反应你所在的网络可能打不开 Google 的页面（在中国大陆很常见）。用邮箱和密码注册、登录都可以。

14. 一页看懂隐私

  • 截图只在你提问或要下一步时发给 AI，或者在你自己打开的自动推进发现屏幕变化时发送。自动推进检查屏幕变化的工作在你的电脑上完成。
  • 只共享一个窗口时，屏幕上的其他内容在发送前都会被涂灰。如果你选择共享整块屏幕，就会发送整块屏幕。
  • 随图一起发送的还有：你输入的内容、窗口标题、这个窗口里各个控件的名称和状态、你在这个窗口里最后点过的控件（只有名称，从不包括内容），以及你的 Windows 版本。Navisual 不监控你的键盘。
  • 你的截图发给你选择的 AI 服务商。托管服务会经过我们的中转服务器；自带 Key 时直接发给那家服务商；用本地模型时留在你的电脑或网络里。在中国大陆，托管服务的请求由通义千问和 DeepSeek 处理。
  • 我们不在服务器上保存你的截图。每一步的截图和你保存的会话一起存在你的电脑上（可以关掉）。设置留在你的电脑上，API Key 存在 Windows 凭据管理器里。
  • 我们会记录你输入的任务和每一步的结果，从不记录截图。可以在设置 → 屏幕指引 → 你输入的内容里关掉对输入任务的记录； AI 在你自己的电脑或网络上运行时，什么都不记录。
  • 语音输入如果你使用，会把你的音频发送给微软的语音服务。
  • 免费档的模型可能会用你发送的内容训练。付费档、自带 Key 和本地方式都不会。
