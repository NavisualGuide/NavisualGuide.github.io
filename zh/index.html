常见问题

Navisual 是做什么的？适合谁用？

它理解你的问题和你当前的窗口，针对你描述的任务给出实时的、一步一步的指引：指出下一步要点的按钮或菜单，并用语音讲解。界面越复杂越有用：工具成百上千的应用、藏在好几层下面的设置，或者要跨好几个应用的任务。适合任何在陌生软件里卡住的人：学习新软件、带家人走完一个安装向导，或者只是想不起某个设置在哪里。就像有个熟手坐在你旁边帮你指，只是每一下都由你自己点。

AI 会控制我的鼠标吗？

不会。Navisual 只指出该点哪里，并讲解下一步。每一次点击、每一次按键、每一次确认，都是你自己做。

在中国大陆能用吗？需要 VPN 吗？

能用，不需要 VPN。在中国大陆，免费档和付费档的请求由通义千问和 DeepSeek 处理（隐私政策第 2 节有说明）。Google 登录在大陆可能打不开，用邮箱注册和登录就行。下载安装包和自动更新也都在大陆实测过，可以正常使用。

支持中文吗？能用 DeepSeek 和通义千问吗？

支持。界面有简体中文和繁体中文，AI 用你输入的语言回答。要用自己的 Key，在「设置 → 服务商」里选 DeepSeek 或 Qwen，填入 API Key 即可。DeepSeek 选 deepseek-flash（设置里标着“能看屏幕”）时会上传截图；选 deepseek-v4-pro 时只传文字，不上传截图。Qwen 支持看截图。

浏览器里能用吗？命令行呢？

都能用。网页是 Navisual 读得最准的界面之一：网页应用、表单、管理后台、设置页面都没问题，Chrome 和 Edge 还有专门的快速通道。至于终端，Navisual 从不替你运行任何东西：需要输入命令时，它把准确的命令放进剪贴板，你看过之后自己粘贴、自己按回车。网址、文件名，以及其他需要重新打字的内容也一样。一个任务要在浏览器下载、文本编辑器和终端之间来回切换也没问题，你在哪个窗口里，Navisual 就跟到哪个窗口。

哪些数据会离开我的电脑？

你当前窗口的截图（如果你选了某一块屏幕，就是那块屏幕的截图），加上你们的对话文字，发给你选择的 AI 服务商。找控件的工作在你的电脑上完成。Navisual 还会记录你输入的任务和每一步的结果（从不记录截图），除非 AI 运行在你自己的电脑上。注意：免费档的 AI 模型可能会保留这些请求（包括截图）并用来训练；按服务商目前的政策，付费档不会；Ollama 则一切都留在本地。详见隐私政策。

能完全离线运行吗？

能。在服务商里选择 Ollama，再下载一个能看图的模型（比如 llama3.2-vision）。什么都不会离开你的电脑，Navisual 也什么都不记录。只有一个例外：如果你打开语音输入，它会用到微软的在线语音服务。

支持哪些 Windows 版本？

Windows 10（1809 或更高版本）和 Windows 11。需要 WebView2：Windows 11 自带，Windows 10 上会自动安装。

是开源的吗？

源代码公开，采用 FSL-1.1-ALv2 许可，每个版本发布两年后转为 Apache 2.0。

Windows 提示“Windows 已保护你的电脑”，安全吗？

安全。这是微软的 SmartScreen：任何新发布的软件，在下载量积累到一定程度之前都会触发这个提示。它看的是下载量，不是安全性，即使软件做了正规的代码签名也会出现。Navisual 的安装包有代码签名（Azure Trusted Signing），源代码也完全公开（FSL）。点更多信息，再点仍要运行即可继续。安装的人多了，这个提示就会消失。
